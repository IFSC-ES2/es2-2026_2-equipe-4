# Definition of Done — PublicaIFSC

Um item do backlog será considerado **concluído** somente quando todas as condições aplicáveis abaixo forem atendidas:

- [ ] A implementação ou documentação prevista na issue foi concluída.
- [ ] Os critérios de aceitação registrados na issue foram atendidos.
- [ ] As alterações estão versionadas no repositório.
- [ ] O desenvolvimento foi realizado em branch própria, criada a partir da `entrega-2`.
- [ ] A alteração foi submetida por Pull Request.
- [ ] O Pull Request está vinculado à issue correspondente.
- [ ] Pelo menos um integrante diferente do autor revisou e aprovou o Pull Request.
- [ ] Os checks automáticos configurados no repositório foram executados com sucesso, quando aplicável.
- [ ] A documentação foi atualizada sempre que a alteração afetar escopo, arquitetura, configuração ou uso do sistema.
- [ ] O uso de inteligência artificial foi registrado em `USO-IA.md`, quando aplicável.
- [ ] O Pull Request contém apenas alterações relacionadas à issue e não inclui arquivos desnecessários ou informações sensíveis.
- [ ] A integração ao ramo principal é feita por Pull Request e commit de mesclagem, sem commits diretos na `main`.

# Observação

Para itens exclusivamente documentais, requisitos de implementação e testes de código são considerados não aplicáveis, mas revisão, critérios de aceitação, versionamento, Pull Request, checks e atualização documental continuam obrigatórios.
