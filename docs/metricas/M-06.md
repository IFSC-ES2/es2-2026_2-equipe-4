# M-06 — Densidade de Defeitos

## Classificação
Processo

## Objetivo
Avaliar a quantidade de defeitos encontrados em relação ao tamanho do código desenvolvido.

## Definição ou fórmula
Densidade de defeitos = número de bugs / KLOC

KLOC representa mil linhas de código.

## Fonte dos dados
Issues de bugs do GitHub e quantidade de linhas de código do projeto.

## Frequência de atualização
A cada sprint ou entrega.

## Responsável pelo acompanhamento
Juliano Tavares

## Datas dos acompanhamentos
A preencher ao longo do projeto.

## Valores coletados
A preencher ao longo do projeto.

## Interpretação
Valores elevados indicam maior concentração de defeitos no código. A redução da densidade ao longo do projeto pode indicar melhoria da qualidade.
