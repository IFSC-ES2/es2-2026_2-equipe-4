# M-07 — Variação de Cronograma

## Classificação
Projeto

## Objetivo
Avaliar se o andamento do projeto está de acordo com o planejamento definido.

## Definição ou fórmula

Variação de cronograma = progresso realizado - progresso planejado

A comparação será feita com base na quantidade ou no percentual de itens efetivamente concluídos em relação aos itens planejados para o período.

## Fonte dos dados
Baseline, backlog, GitHub Issues e board do projeto.

## Frequência de atualização
A cada sprint ou marco do projeto.

## Responsável pelo acompanhamento
Gabriel Ferreira

## Datas dos acompanhamentos
A preencher ao longo do projeto.

## Valores coletados
A preencher ao longo do projeto.

## Interpretação
Valor igual a zero indica alinhamento com o planejamento. Valor positivo indica avanço em relação ao planejado e valor negativo indica atraso.
