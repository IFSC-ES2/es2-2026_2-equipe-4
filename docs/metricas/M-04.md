# M-04 — Acoplamento entre Classes (CBO)

## Classificação
Produto

## Objetivo
Avaliar o grau de dependência existente entre as classes do sistema.

## Definição ou fórmula
CBO = quantidade de outras classes distintas das quais uma classe depende diretamente.
