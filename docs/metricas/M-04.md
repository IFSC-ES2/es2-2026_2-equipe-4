# M-04 — Acoplamento entre Classes (CBO)

## Classificação
Produto

## Objetivo
Avaliar o grau de dependência existente entre as classes do sistema.

## Definição ou fórmula
CBO = quantidade de outras classes distintas das quais uma classe depende diretamente.

## Fonte dos dados
Código-fonte.

## Frequência de atualização
A cada entrega do projeto.

Escopo: tipos Java de produção versionados em `src/backend/artigos/src/main/java/`.
Cada tipo do projeto referenciado diretamente no código foi contado uma vez por
tipo de origem, mesmo quando aparece mais de uma vez. Foram desconsiderados
comentários, literais, imports sem uso, testes e tipos externos (Java, Spring,
MongoDB e outras bibliotecas). Esta coleta mede apenas o acoplamento interno;
ferramentas que incluem dependências externas podem apresentar outros valores.

## Interpretação
Valores elevados indicam maior acoplamento e dependência entre classes, podendo dificultar manutenção e teste. Valores menores tendem a indicar maior modularidade.
