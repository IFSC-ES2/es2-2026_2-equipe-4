# M-04 — Acoplamento entre Classes (CBO)

## Classificação
Produto

## Objetivo
Avaliar o grau de dependência existente entre as classes do sistema.

## Definição ou fórmula
**CBO = quantidade de outras classes distintas das quais uma classe depende diretamente.**

## Fonte dos dados
Código-fonte.

## Frequência de atualização

no CBO interno. Da mesma forma, dependências externas foram excluídas de todas as classes.

## Interpretação
O acoplamento interno aumentou na Sprint 2 principalmente pela introdução das funcionalidades
de cadastro e autenticação. As novas classes de serviço, controladores e segurança passaram a
se relacionar com entidades, DTOs, repositórios e componentes de autenticação.
