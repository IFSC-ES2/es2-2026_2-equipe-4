# M-03 — Cobertura de Testes

## Classificação
Produto

## Objetivo
Avaliar qual percentual do código do sistema é executado pelos testes automatizados.

## Definição ou fórmula
Cobertura (%) = (linhas executadas pelos testes / total de linhas executáveis) × 100

## Fonte dos dados
Relatório gerado pela ferramenta de testes e cobertura do projeto.

## Frequência de atualização
A cada execução da suíte de testes nas entregas.

## Responsável pelo acompanhamento
Juliano Tavares

## Datas dos acompanhamentos
- 17/09/2026
- 01/10/2026

## Valores coletados

### 17/09/2026 — Sprint 1

- Cobertura consolidada: 64,20% (104 de 162 linhas)
- Backend: 55,13% (43 de 78 linhas)
- Frontend: 72,61% (61 de 84 linhas)

### 01/10/2026 — Sprint 2

- Cobertura consolidada: 77,08% (343 de 445 linhas)
- Backend: 72,70% (221 de 304 linhas)
- Frontend: 86,52% (122 de 141 linhas)

## Interpretação
Quanto maior a porcentagem, mais partes do código foram testadas automaticamente. Mesmo assim, é importante verificar se os testes realmente conferem o comportamento esperado.
