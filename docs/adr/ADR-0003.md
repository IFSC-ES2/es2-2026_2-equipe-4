# ADR-0003: Estatico para React

## Status

**Aceita**

## Contexto

Foi decidido levando em cosideração as complexidades, trabalho e tempo que séria necessário para adaptar/alterar para React o Frontend que inicialmente séria feito por Estático.

## Decisão

Alteração de HTML estático para a utilização de React.

## Alternativas consideradas

Nenhuma outra alternativa foi considerada/encontrada.

## Consequências

Consequências diretas para a arquitetura de software, a produtividade do time e a manutenção a longo prazo, 
dividindo-se entre grandes facilidades e desafios operacionais marcantes.

### Consequências positivas

- Reutilização de Componentes: O desenvolvimento é baseado em componentes isolados. 
Você cria um botão ou um formulário uma única vez e o reutiliza em todo o projeto, 
garantindo consistência e economizando tempo.
- Alta Performance com Virtual DOM: O React cria uma cópia na memória da estrutura da página (DOM). 
Quando algo muda, ele atualiza apenas o fragmento necessário em vez de recarregar a tela inteira, 
tornando a navegação ultrarrápida.
- Fácil Transição para Mobile: Com o conhecimento de React, aprender React Native 
para criar aplicativos de celular (iOS e Android) se torna um processo muito simples e rápido.

### Consequências negativas ou riscos

- Sobrecarga de Escolhas (Falta de Padrão): Como o React não é um framework completo (como Angular ou Vue), 
ele não dita regras de como estruturar as pastas ou quais ferramentas usar. 
Se o time não for experiente, o projeto pode virar uma "colcha de retalhos" bagunçada.
- Velocidade de Atualização: O ecossistema muda muito rápido. 
Ferramentas e boas práticas de dois anos atrás podem se tornar obsoletas rapidamente, 
exigindo estudo constante e refatoração de código.
- Curva de Aprendizado do JSX: O React mistura HTML dentro do JavaScript (chamado JSX). 
No início, essa sintaxe pode parecer confusa e desencorajar desenvolvedores iniciantes.

## Ações necessárias

Criação do Frontend ser começada por React invés da criação de estático e depois adaptar/alterar para React.

## Relação com o MVP

A interação do usuário com o sistema e comunicação com a API.
