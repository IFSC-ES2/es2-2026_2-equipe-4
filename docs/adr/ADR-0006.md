# ADR-0006: Consolidação da arquitetura e stack implementadas

## Status

Aceita em 16/11/2026 como consolidação documental das decisões implementadas.
Não altera o código nem substitui os registros históricos [ADR-0001](ADR-0001.md)
e [ADR-0002](ADR-0002.md).

## Contexto

As ADRs iniciais registram a arquitetura em camadas e a stack planejada, mas
foram escritas antes das mudanças para projetos, React e GridFS. A issue #130
registrou a necessidade de consolidar os registros com o estado implementado.

## Decisão

O produto atual usa React/Vite no frontend, Spring Boot na API, MongoDB para
usuários e projetos e GridFS para arquivos. A comunicação é HTTP entre browser
e API; somente a API acessa o banco. O backend organiza responsabilidades em
controllers, services e repositories, com DTOs e autenticação JWT integrada
ao Spring Security. Docker Compose reúne os serviços para execução local.
MySQL permaneceu alternativa e não foi adotado.

## Consequências

- O estado real está detalhado em [ARQUITETURA.md](../ARQUITETURA.md).
- ADR-0001 e ADR-0002 permanecem como histórico do planejamento original.
- As decisões de mudança de tema, frontend e autenticação seguem registradas
  em [ADR-0003](ADR-0003.md), [ADR-0004](ADR-0004.md) e [ADR-0005](ADR-0005.md).
- A ausência de deploy remoto é uma decisão separada na [ADR-0007](ADR-0007.md).
