# ADR-0007: Ambiente local reprodutível para o Release Candidate

## Status

Aceita em 16/11/2026 para descrever o estado conhecido naquele momento;
superada em 17/11/2026 pela implantação publicada descrita em [DEPLOY.md](../DEPLOY.md).

## Contexto

Na revisão documental de 16/11, as issues #161 a #164, relativas a staging,
deploy automatizado, validação e documentação de deploy, constavam como não
planejadas e o ambiente conhecido era o Docker Compose local. Em 17/11, a
equipe publicou a aplicação no Render e configurou a persistência no MongoDB
Atlas; os endereços e instruções atuais estão em [DEPLOY.md](../DEPLOY.md).

## Decisão

Esta ADR registra a decisão válida na revisão de 16/11: usar Docker Compose
como ambiente de validação reproduzível, sem declarar um deploy remoto que
ainda não estava disponível. A implantação posterior no Render é o ambiente
publicado atual; Docker Compose continua sendo a alternativa local. Não há
staging configurado.

## Consequências

- No estado registrado por esta ADR, avaliação exigia execução local; após a
  implantação, endereços e acesso de avaliação estão em [DEPLOY.md](../DEPLOY.md).
- A ausência de staging permanece uma limitação; consulte o registro de riscos.
