# ADR-0007: Ambiente local reprodutível para o Release Candidate

## Status

Aceita em 16/11/2026 para descrever o estado da Entrega 9.

## Contexto

As issues #161 a #164, relativas a staging, deploy automatizado, validação e
documentação de deploy, foram fechadas como não planejadas em 11/11. O
repositório contém Docker Compose e instruções locais, mas não registra URL,
workflow ou deployment remoto. O enunciado da Entrega 9 solicita ambiente
acessível ou equivalente reproduzível.

## Decisão

O ambiente de validação documentado para este RC é o Docker Compose local
descrito em [DEPLOY.md](../DEPLOY.md). Não declarar staging ou deploy remoto
como entregue. A ausência de ambiente remoto é uma limitação conhecida e
permanece no risco R13.

## Consequências

- A pessoa avaliadora precisa executar a aplicação localmente; instruções e
  endereços estão em [DEPLOY.md](../DEPLOY.md) e [README.md](../../README.md).
- Cada avaliador cria sua própria conta; não há credencial compartilhada.
- Disponibilizar staging exigirá decisão e configuração posteriores, além de
  atualizar esta ADR e o registro de riscos.
